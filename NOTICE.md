## Status of this repository

EPS16plusSmasher combines code derived from two projects:

**1. EnsoniqEPS16Plus by summitt (Null Lexicon)**
https://github.com/summitt/EnsoniqEPS16Plus

The MIDI/sysex protocol layer (the `EPS16` class in `EPS16plusSmasher.py`)
is a port of that project's `eps.js`. That repository does not state a
license. This port is published with full credit while permission from the
author has been requested; it will be changed or removed at the author's
request. No license is granted here for the portions derived from it.

If this tool is useful to you, please support summitt's work:
https://patreon.com/null0perat0r

**2. Transwave Atom Smasher by handsthatstrike (MIT license)**
https://github.com/handsthatstrike/Transwave-Atom-Smasher

The Transwave Smasher section is a native Python port of that project's
Perl/SoX processing. Its license follows.
